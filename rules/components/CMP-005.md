# CMP-005 — Dialog accessibility pattern

**Requirement:** Modal dialogs MUST: label the dialog, trap focus, close on Escape, restore focus, and inert background content.

**Bad:** Div overlay, focus escapes, no Escape.

**Good:** APG-compliant dialog component.

- Automated checks / lint / a11y tooling where applicable
- Design or engineering review
