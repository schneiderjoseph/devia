# CMP-003 — Data table headers

**Requirement:** Data tables MUST use proper header cells associated with data.

**Bad:** Bold first row of td only.

**Good:** th scope="col" (or row headers when needed).

- Automated checks / lint / a11y tooling where applicable
- Design or engineering review
