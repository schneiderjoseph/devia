# CMP-002 — Disabled action explains enablement

**Requirement:** If a primary action is disabled, the UI SHOULD explain how to enable it.

**Bad:** Gray Save with no hint.

**Good:** Inline hint: ‘Complete required fields to save’.

## Validation

- Design or engineering review
