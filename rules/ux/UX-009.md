# UX-009 — Required fields indicated in text

**Requirement:** Required fields MUST be indicated in text (not color alone).

**Bad:** Red asterisk only, unexplained.

**Good:** ‘Required’ in legend/label text (asterisk OK if explained once).

- Design or engineering review
