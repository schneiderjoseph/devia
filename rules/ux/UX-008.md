# UX-008 — Field errors identifiable and actionable

**Requirement:** Validation errors MUST identify the field, describe the problem, and how to fix it.

**Bad:** Toast: ‘Invalid form’.

**Good:** Inline error + focus move to first error; summary for long forms.

- Automated checks / lint / a11y tooling where applicable
- Design or engineering review
