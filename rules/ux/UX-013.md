# UX-013 — Progressive disclosure

**Requirement:** Advanced or rare options SHOULD be progressive, not dumped equally with core fields.

**Bad:** 40 equal fields on one screen for a simple task.

**Good:** Core fields first; advanced collapsed or stepped.

## Validation

- Design or engineering review
