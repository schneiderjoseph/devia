# UX-007 — Persistent accessible labels

**Requirement:** Every field MUST have a persistent accessible label. Placeholder-only labeling is forbidden.

**Bad:** placeholder="Email" with no label.

**Good:** Visible label associated via for/id or wrapping; placeholder optional hint only.

- Automated checks / lint / a11y tooling where applicable
- Design or engineering review
