# UX-010 — Complete UI states for data views

**Requirement:** Key screens MUST define empty, loading, error, and success/populated states where data can be absent or fail.

**Bad:** Blank white area while fetching; crash on error.

**Good:** Skeleton/spinner; empty + CTA; recoverable error.
