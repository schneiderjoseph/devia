# UX-003 — Navigation mirrors user mental model

**Requirement:** Top-level nav labels SHOULD match user tasks/objects, not internal org charts.

**Bad:** Nav: ‘Module A / Module B’ from engineering.

**Good:** Nav: task/object names users recognize.

## Validation

- Design or engineering review
