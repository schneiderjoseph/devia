# UX-002 — System status visible

**Requirement:** After user-initiated actions that take noticeable time or change data, the UI MUST show progress or confirmation.

**Bad:** Save with no toast/spinner/inline confirmation.

**Good:** Pending state + success/error outcome.

## Validation

- Automated checks / lint / a11y tooling where applicable
- Design or engineering review
