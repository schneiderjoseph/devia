# UX-001 — One primary action per view

**Requirement:** Each primary view MUST expose a clear primary action (or explicitly be read-only).

**Bad:** Three equally weighted CTAs competing in the header.

**Good:** One primary CTA; secondary actions visually quieter.

- Task success / heuristic review
