# UX-012 — Human-readable errors

**Requirement:** User-facing errors MUST NOT expose stack traces, SQL, or internal codes as the only message.

**Bad:** PQXZ_99 constraint violation.

**Good:** Plain language + optional reference id for support.

- Design or engineering review
