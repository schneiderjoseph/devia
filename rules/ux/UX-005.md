# UX-005 — Current location indicated

**Requirement:** Primary navigation MUST indicate the current section/page.

**Bad:** All nav items look identical while on a child page.

**Good:** Active state on current section; page title / h1 align.

## Validation

- Automated checks / lint / a11y tooling where applicable
- Design or engineering review
