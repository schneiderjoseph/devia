# A11Y-010 — Target size

**Requirement:** Pointer targets MUST meet WCAG 2.5.8 (24×24 CSS px minimum); prefer 44×44 for primary touch UIs.

**Bad:** 16×16 icon hit area.

**Good:** Adequate padding/hit slop.
