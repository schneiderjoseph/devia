# A11Y-011 — Reflow without loss of use

**Requirement:** Content MUST reflow without loss of information or functionality at 320 CSS px width (except exempt content).

**Bad:** Broken layout forcing x-scroll for login.

**Good:** Stacked layout / responsive shell.
