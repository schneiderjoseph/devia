# A11Y-009 — UI component contrast

**Requirement:** Meaningful non-text UI MUST meet 3:1 against adjacent colors where required.

**Bad:** Pale input border invisible against background.

**Good:** Border/token meets 3:1.

## Validation

- Automated checks / lint / a11y tooling where applicable
- Design or engineering review
