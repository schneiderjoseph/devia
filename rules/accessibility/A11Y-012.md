# A11Y-012 — Respect reduced motion

**Requirement:** Non-essential motion MUST respect prefers-reduced-motion.

**Bad:** Large parallax with no reduce path.

**Good:** Instant state change or minimal opacity fade when reduced.

- Automated checks / lint / a11y tooling where applicable
- Design or engineering review
