# API-001 — Requests are validated against an explicit schema

**Requirement:** Every endpoint MUST declare the shape it accepts and reject anything else, including unknown fields on write operations, and MUST NOT rely on downstream layers to catch bad input.

**Bad:** The handler reads whatever properties happen to exist on the body.

**Good:** A declared schema validates the body, params and query before the handler runs.

## Validation

- Schema present for every endpoint in the diff
- Test: unknown field on a write is rejected

- Status: `active`
- Priority: `P0`
- Exceptions: `none`
