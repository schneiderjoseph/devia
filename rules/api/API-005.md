# API-005 — Collections are bounded

**Requirement:** Endpoints returning collections MUST paginate with a maximum page size, and MUST NOT allow an unbounded result set through a parameter.

**Bad:** `GET /invoices` returning every row a tenant has ever had.

**Good:** Cursor pagination with a hard maximum, documented in the endpoint contract.

## Validation

- A maximum limit is enforced server-side
- Test: an oversized limit is clamped or rejected
