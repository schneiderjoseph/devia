# API-006 — One capability, one surface

**Requirement:** A business capability SHOULD have exactly one implementation. A second endpoint that recomputes the same rule differently is a defect, not a shortcut.

**Bad:** The mobile client gets its own totals endpoint that rounds differently from the web one.

**Good:** Both clients call the same endpoint; presentation differs, the rule does not.

## Validation

- Search for an existing implementation before adding one
- Record the surface in `.devia/02_SURFACES.md`
