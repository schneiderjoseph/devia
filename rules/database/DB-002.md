# DB-002 — Applied migrations are immutable

**Requirement:** A migration that has run in any shared environment MUST NOT be edited. Corrections ship as a new migration.

**Bad:** Editing yesterday's migration so it 'works now' — silently diverging every environment that already ran it.

**Good:** A new corrective migration that brings every environment to the same state.

## Validation

- Confirm no already-applied migration file is modified in the diff
