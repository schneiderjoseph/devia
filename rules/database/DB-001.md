# DB-001 — Every schema change is a versioned migration

**Requirement:** Schema changes MUST ship as ordered, committed migration files that run in CI and in every environment. Schema MUST NOT be changed by hand in any environment, least of all production.

**Bad:** A column added through a database console; the next deploy fails on a machine nobody touched.

**Good:** `migrations/20260903_add_invoice_currency.sql`, applied by the deploy pipeline.

## Validation

- Migration file present in the diff
- Migration runs on a clean database in CI

## Lifecycle

- Status: `active`
- Priority: `P0`
- Exceptions: `none`
