# DB-006 — Queries the application actually runs are indexed

**Requirement:** Filter, join and sort columns used by real queries SHOULD be indexed, and an index SHOULD be justified by a query rather than added speculatively.

**Bad:** A list endpoint scanning a million rows on every request.

**Good:** An index on the actual predicate, verified with an execution plan before and after.

## Validation

- Execution plan for the new or changed query
