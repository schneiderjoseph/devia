# DB-004 — Backups exist and restore has been rehearsed

**Requirement:** Production data MUST be backed up on a defined schedule, and the restore MUST have been performed at least once, with the date and the result recorded. An untested backup is not a backup.

**Bad:** Nightly snapshots nobody has ever restored.

**Good:** Snapshots plus a rehearsed restore into a scratch environment, recorded with the elapsed time.

## Validation

- Backup schedule documented
- Restore drill recorded with a date

- Status: `active`
- Priority: `P0`
- Exceptions: `none`
