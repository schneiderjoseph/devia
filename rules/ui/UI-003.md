# UI-003 — Semantic tokens over raw hex

**Requirement:** Product UI MUST consume semantic tokens, not scattered raw hex (except in token definitions).

**Bad:** #ff3b30 hard-coded in 12 components.

**Good:** Components reference danger / primary tokens.

- Automated checks / lint / a11y tooling where applicable
- Design or engineering review
