# UI-004 — Not color alone

**Requirement:** Status and meaning MUST NOT be conveyed by color alone.

**Bad:** Red/green dots only for status.

**Good:** Color + text/icon/pattern.

- Automated checks / lint / a11y tooling where applicable
- Design or engineering review
