# UI-005 — Spacing scale

**Requirement:** Spacing MUST use the system scale (e.g. 4/8-based tokens), not arbitrary values.

**Bad:** margin: 13px 7px.

**Good:** space.3 / --space-3.

## Validation

- Automated checks / lint / a11y tooling where applicable
- Design or engineering review
