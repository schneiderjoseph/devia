# UI-001 — Type from tokens

**Requirement:** UI text sizes/weights/line-heights MUST use design tokens (or the system type scale), not random px values.

**Bad:** font-size: 13.5px inline on one card.

**Good:** --font-size-sm / role token.

## Validation

- Automated checks / lint / a11y tooling where applicable
- Design or engineering review

## Lifecycle

- Status: `active`
- Priority: `P1`
- Exceptions: `documented-only`
