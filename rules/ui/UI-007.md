# UI-007 — Icon-only controls named

**Requirement:** Icon-only controls MUST have an accessible name (aria-label, aria-labelledby, or visually hidden text).

**Bad:** Trash icon button with no name.

**Good:** aria-label="Delete order".

- Automated checks / lint / a11y tooling where applicable
- Design or engineering review
