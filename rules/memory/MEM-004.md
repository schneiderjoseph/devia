# MEM-004 — Registry identifiers are monotone and never reused

**Requirement:** Gap and debt identifiers MUST increase and MUST NOT be reused after closure, so that an old reference never resolves to a different subject.

**Bad:** Reusing `G7` for a new gap after the original was closed.

**Good:** The next gap is `G23`; `G7` stays closed and readable in history.

## Validation

- `devia validate` reports no duplicate or reused id
