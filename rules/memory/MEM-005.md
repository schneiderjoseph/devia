# MEM-005 — Verify before recording

**Requirement:** A gap, debt or never/always line MUST be checked against the code before it is written. A false line is worse than a missing one because it is trusted.

**Bad:** Recording 'no rate limiting anywhere' without opening the middleware that implements it.

**Good:** The claim is checked, then recorded with the file that shows it.

## Validation

- Each new registry line names where the claim was verified
