# MEM-008 — Memory points at documentation, it does not duplicate it

**Requirement:** Memory files MUST reference the authoritative document or file for detail instead of copying it, so there is exactly one place to change when the detail changes.

**Bad:** The full table definition pasted into the memory, drifting from the migration within a week.

**Good:** '`invoice` — defined in `migrations/20260812_invoice.sql`, rules in `docs/BILLING.md` §4.'

## Validation

- New memory content links rather than copies
