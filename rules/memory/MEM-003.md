# MEM-003 — Debt lines are closed only by the change that discharges them

**Requirement:** A debt line MUST be removed in the same change that makes it false, and MUST be reduced rather than deleted when the work is partly done. Removing a line for tidiness is forbidden.

**Bad:** Deleting three debt lines during cleanup because they 'look old'.

**Good:** The line for the fixed part is removed; the remainder is rewritten to what is still true.

## Validation

- Every removed debt line is discharged by the same diff
