# MEM-007 — No perishable facts in overview or index files

**Requirement:** Memory files describing what the project is MUST NOT contain counters, current branches, sprint plans or 'next we will' statements. Perishable facts belong to the registries and the tracker.

**Bad:** '42 tests passing, currently building the invoice screen' in `00_OVERVIEW.md`.

**Good:** The overview describes the product and the stack; progress lives in the registries.

- `devia validate` finds no perishable-fact markers
