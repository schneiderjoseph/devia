# MEM-010 — Never/always lines come from real incidents

**Requirement:** `10_NEVER_ALWAYS.md` SHOULD grow one line at a time, each earned by a mistake that actually happened or a decision that was actually contested. Speculative rules dilute the file and train agents to skim.

**Bad:** Forty generic best-practice lines copied from a blog post.

**Good:** Six lines, each traceable to a bug this project actually shipped.

## Validation

- Each line names the trap and the correct move
