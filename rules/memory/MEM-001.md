# MEM-001 — Undecided is never coded as a silent truth

**Requirement:** When a rule has not been decided, the implementation MUST make its assumption visible and the open question MUST be recorded in `.devia/11_GAPS.md`. Silent defaults MUST NOT become de facto policy.

**Bad:** The code rounds down, nobody decided that, and in six months it is 'how it works'.

**Good:** A named constant, a comment pointing at the gap line, and a gap entry awaiting a decision.

## Validation

- The gap registry contains the open question
- The code's assumption is visible

- Status: `active`
