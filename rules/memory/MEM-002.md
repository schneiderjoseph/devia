# MEM-002 — Decided but not built is recorded as debt

**Requirement:** When the project has decided a rule and the code does not honour it yet, a debt line MUST be added to `.devia/12_DEBT.md` — even when the agent is not going to fix it now.

**Bad:** Noticing that a validation is missing and moving on because it was not the task.

**Good:** A debt line naming the rule, the place, and what it would take.

## Validation

- The debt registry gained a line for what was found
