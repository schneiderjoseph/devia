# MEM-011 — Never delete a registry line you did not discharge

**Requirement:** An agent MUST NOT remove a gap or debt line to make a report look cleaner, and MUST NOT close a line on the basis that it 'seems handled'. Closure requires naming the change that closed it.

**Bad:** Clearing the debt file during a refactor because it was 'out of date'.

**Good:** Each closure names its commit; anything unverified stays open.

## Validation

- Removed lines are justified in the same diff
