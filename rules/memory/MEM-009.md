# MEM-009 — Code and memory ship in the same change

**Requirement:** When a change makes a memory file false, the same change MUST fix it. `impact-map.yaml` names which files each kind of change touches.

**Bad:** A new endpoint merged on Monday; `02_SURFACES.md` updated 'later'.

**Good:** The endpoint and the surfaces entry land in the same pull request.

## Validation

- `devia doctor` reports no memory lag for the surfaces touched
- The impact map entry was honoured
