# SEC-003 — External input is validated before use

**Requirement:** Every input crossing a trust boundary — request bodies, query strings, headers, webhooks, uploads, third-party responses, model output — MUST be validated against an explicit schema and rejected when it does not match.

**Bad:** `JSON.parse(body)` is passed straight to an ORM write.

**Good:** The body is parsed into a declared schema; unknown fields are rejected; types and ranges are enforced.

## Validation

- Every new endpoint has a schema
- Test: malformed and oversized input is rejected
