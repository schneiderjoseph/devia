# SEC-007 — Webhooks are verified and replay-protected

**Requirement:** Inbound webhooks MUST verify the provider signature against the raw body before any processing, MUST reject stale timestamps, and MUST be idempotent on the provider event id.

**Bad:** The handler trusts the payload and credits the account twice when the provider retries.

**Good:** Signature verified on the raw body; event id stored; a repeat delivery is a no-op that returns 200.

## Validation

- Test: bad signature rejected
- Test: duplicate delivery changes nothing
- Test: stale timestamp rejected
