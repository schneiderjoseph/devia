# SEC-004 — Internal error detail never reaches a production client

**Requirement:** Stack traces, SQL text, file paths, internal hostnames and framework diagnostics MUST NOT be returned to clients in production. The client gets a stable code and a human-readable message; the detail goes to the log.

**Bad:** A 500 response containing the query and the table name.

**Good:** `{ "error": "payment_failed", "message": "We could not process this payment." }` plus a correlated log entry.

## Validation

- Test an error path against the production configuration
- Confirm the error handler is the last middleware

- Status: `active`
