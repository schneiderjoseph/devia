# SEC-010 — Least privilege for every credential and role

**Requirement:** Application credentials, CI tokens and cloud roles MUST hold the narrowest set of permissions the task needs, and MUST be scoped to the environment they serve.

**Bad:** One database superuser shared by the app, the migration job and the analytics reader.

**Good:** A migration role that can alter schema, an app role that cannot, a read-only analytics role.

## Validation

- Review the permission set of each credential the change touches
