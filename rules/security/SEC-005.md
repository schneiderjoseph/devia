# SEC-005 — Tenant and user isolation is enforced and tested

**Requirement:** Every query touching user- or tenant-scoped data MUST be constrained by the actor's scope, and that constraint MUST be covered by a test that fails when the constraint is removed.

**Bad:** A list endpoint filters by tenant in the UI only.

**Good:** The query carries the tenant predicate (or a row-level policy does), and a test proves cross-tenant reads return nothing.

## Validation

- Cross-tenant read test
- Cross-tenant write test
- Test fails if the predicate is deleted
