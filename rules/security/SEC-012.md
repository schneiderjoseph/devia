# SEC-012 — Credentials are stored irreversibly and compared safely

**Requirement:** Passwords MUST be stored with a current memory-hard hash (argon2id or bcrypt with a modern cost). API tokens MUST be stored hashed. Secret comparisons MUST be constant time.

**Bad:** SHA-256 without a salt, or `token === storedToken`.

**Good:** argon2id with per-credential salt; tokens stored as hashes; comparisons use a timing-safe function.

## Validation

- Read the hashing configuration
- Confirm no reversible storage of a credential
