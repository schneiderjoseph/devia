# SEC-006 — Sessions expire, rotate and can be revoked

**Requirement:** Sessions and tokens MUST have a bounded lifetime, MUST be rotated on privilege change, and MUST be revocable server-side. Logout MUST invalidate server state, not only client storage.

**Bad:** A signed token valid for a year with no revocation list.

**Good:** Short-lived access token, rotating refresh token, revocation on logout and on password change.

## Validation

- Test: a revoked session is rejected
- Test: privilege change invalidates the old session
