# SEC-011 — Dependency and secret scanning run in CI

**Requirement:** CI MUST run a dependency audit and a secret scan on every pull request, and MUST fail the build on a known critical finding unless a human records an explicit, time-bounded acceptance.

**Bad:** The audit runs weekly by email and nobody reads it.

**Good:** The audit is a required check; a critical advisory blocks the merge.

## Validation

- The workflow contains both jobs
- Both are required checks in branch protection
