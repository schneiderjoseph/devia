# SEC-002 — No secrets in source, config, logs or client bundles

**Requirement:** Credentials, API keys, tokens and private keys MUST NOT be committed, embedded in a client bundle, printed in logs, or pasted into an issue, prompt or transcript.

**Bad:** `STRIPE_SECRET_KEY` in a `.env` that is committed, or echoed by a debug log line.

**Good:** Secrets come from the platform secret store at runtime; `.env.example` holds names, never values.

## Validation

- Secret scan in CI
- Grep the client bundle for key patterns
- Rotate any secret that ever touched the repository
