# SEC-009 — Transport and browser security headers are set

**Requirement:** Production traffic MUST be TLS only, with HSTS, a content security policy, `X-Content-Type-Options`, a referrer policy, and cookies marked `Secure`, `HttpOnly` and `SameSite` as appropriate.

**Bad:** A session cookie without `HttpOnly` on a site served over both HTTP and HTTPS.

**Good:** HTTPS enforced with redirect and HSTS; CSP without `unsafe-inline`; cookies hardened.

## Validation

- Inspect response headers on a deployed environment
- Check cookie flags
