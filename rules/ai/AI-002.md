# AI-002 — No secrets or unnecessary personal data in prompts

**Requirement:** Prompts, tool definitions and few-shot examples MUST NOT contain credentials, and MUST NOT contain personal data beyond what the task requires.

**Bad:** An API key embedded in a system prompt so the model can 'call the service'.

**Good:** The model requests an action; the server holds the credential and performs it.

## Validation

- Grep prompt templates for key patterns
- Review the personal fields passed in context
