# AI-003 — Model output is validated before it reaches a system of record

**Requirement:** Generated content MUST be validated against a schema and business rules before it is written to a database, executed, rendered as markup, or sent to a customer.

**Bad:** Model JSON parsed and inserted directly, including a field the schema does not have.

**Good:** Output validated, coerced, rejected on mismatch, and logged when it fails.

## Validation

- Schema validation on the model output path
- Test: malformed output is rejected
