# AI-004 — Irreversible agent actions require a human

**Requirement:** An autonomous agent MUST NOT perform an irreversible or externally visible action — money movement, deletion, sending to customers, publishing — without an explicit human approval step or a documented, bounded authorization.

**Bad:** A nightly agent that emails customers whenever it thinks something is wrong.

**Good:** The agent drafts; a human approves; the approval is recorded.

## Validation

- Approval step present for irreversible tools
- Approval recorded
