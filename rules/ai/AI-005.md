# AI-005 — Prompts, tools and model versions are versioned artifacts

**Requirement:** Prompts, tool schemas and model identifiers SHOULD live in version control and change through review, because a prompt change is a behaviour change.

**Bad:** A prompt edited in a dashboard, with production behaviour changing and no diff anywhere.

**Good:** Prompts in the repository, model id pinned in configuration, changes reviewed.

## Validation

- Prompt and model id in version control
