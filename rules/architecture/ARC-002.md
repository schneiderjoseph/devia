# ARC-002 — Non-trivial decisions are recorded

**Requirement:** A decision that constrains future work — a datastore, a protocol, a boundary, an external dependency, a state machine — MUST be recorded as an ADR before or with the change that implements it.

**Bad:** A queue appears in the codebase and nobody can say why it is there.

**Good:** `docs/adr/0007-outbox-instead-of-queue.md` states the context, the options, and the consequence.

## Validation

- An ADR file exists for the decision
- `.devia/01_ARCHITECTURE.md` points to it
