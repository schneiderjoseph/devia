# ARC-004 — Every new dependency is justified

**Requirement:** Adding a runtime dependency MUST be a recorded decision covering need, maintenance, licence, security history and cost. Trivial functionality MUST NOT pull in a package.

**Bad:** A four-line date format becomes a transitive tree of eleven packages.

**Good:** The formatting uses the platform API; a dependency is added only when it carries real, maintained complexity.

## Validation

- Diff of the manifest and lockfile reviewed
- Justification present in the PR or an ADR
- `npm audit` clean for the added tree
