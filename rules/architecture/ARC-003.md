# ARC-003 — Complexity must be earned

**Requirement:** Infrastructure and architectural complexity — cache layers, queues, extra datastores, microservices, orchestration, GraphQL, multi-region — MUST NOT be introduced without a demonstrated need recorded in an ADR.

**Bad:** Redis is added 'for scale' to a system with forty daily users and no measured latency problem.

**Good:** The slow query is indexed. If a cache is still needed, the ADR records the measurement that proved it.

## Validation

- The need is demonstrated by a measurement or a hard requirement
- An ADR exists
