# ARC-001 — Layer boundaries are respected

**Requirement:** Each layer MUST talk only to the layer below it through its declared interface. UI code MUST NOT reach the database, and transport code MUST NOT contain business rules.

**Bad:** A React page opens a database client and computes a price inline.

**Good:** The page calls an API endpoint; the endpoint calls a service; the service owns the rule and the query.
