# ARC-005 — Business rules live outside transport and framework code

**Requirement:** Domain rules SHOULD be expressed in code that can be tested without HTTP, a framework, or a browser.

**Bad:** A pricing rule lives inside a request handler and can only be exercised through an endpoint.

**Good:** The rule lives in a pure function with unit tests; the handler validates input and calls it.

## Validation

- The rule has a unit test that does not start a server
