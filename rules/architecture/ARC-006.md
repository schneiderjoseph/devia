# ARC-006 — Environment-specific values come from configuration

**Requirement:** Hosts, URLs, credentials, feature flags and limits MUST come from configuration, never from literals in application code, and MUST have a documented default for local development.

**Bad:** `https://api.staging.example.com` hardcoded in a client module.

**Good:** `config.apiBaseUrl`, sourced from the environment, documented in `.env.example`.

## Validation

- Grep the diff for environment hostnames and absolute paths
- `.env.example` updated
