# DATA-003 — Numeric alignment

**Requirement:** Columns of comparable numbers SHOULD be right-aligned (or tabular lining) for scanability.

**Bad:** Left-aligned money column wandering.

**Good:** Tabular nums, consistent decimals.

- Design or engineering review
