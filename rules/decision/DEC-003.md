# DEC-003 — Every major dependency carries a dated, explained version decision

**Requirement:** A framework, runtime or data store MUST be recorded in the register with the version selected, the date it was selected, and the reason. "Always use the latest" is not a decision and MUST NOT be recorded as one; staying on an older version is legitimate when the reason is written down.

**Bad:** The manifest says `next@15`, nobody remembers whether that was chosen or inherited, and every upgrade conversation restarts from zero.

**Good:** `stack.framework: decided`, value `16.x`, package `next`, because "latest stable at initialisation, no migration blocker", dated.

## Validation

- `devia check` reports DEC-STACK when the declared major and the manifest disagree
- `decided_at` and `because` are present
