# DEC-006 — Imagery supports a decided direction, it does not compensate for a missing one

**Requirement:** Visual assets SHOULD be added to serve a direction that already exists. Decoration added while layout, hierarchy, spacing, typography and states are still unresolved SHOULD be treated as a signal that the underlying design decision is missing.

**Bad:** Eight stock images, four gradients and three illustrations on a page whose headings are still three sizes of the same weight.

**Good:** Hierarchy, spacing and states first; imagery once the direction says what the imagery is for.

## Validation

- Design review states which decision the imagery serves
- Reviewed by a human — this one needs judgement, so it warns rather than blocks
