# DEC-004 — A visual identity is never established as a side effect of implementation

**Requirement:** Where the visual direction is `pending`, an agent MUST NOT introduce a style that would function as one — a palette, a typeface pairing, a signature treatment. A visual pattern MUST NOT be adopted on the grounds that it is the common default of generated interfaces.

**Bad:** Purple gradient, dark hero, glassmorphic cards and a floating dashboard, chosen because that is what appears when nothing was asked for.

**Good:** The direction stays pending, the layout ships on the tokens the project already has, and the brand decision stays with the human who owns it.

## Validation

- `design.direction` is decided or delegated before brand-level styling lands
- Design review names the decision the styling implements
