# DEC-001 — An undefined decision is never an implicit permission

**Requirement:** When a decision is recorded as `pending` in `.devia/decisions.yaml`, the implementation MUST NOT encode an answer to it. The agent MUST implement around the pending decision, ask, or record the consequence — a silent default MUST NOT become the project policy.

**Bad:** No visual direction was decided, so the agent shipped a purple gradient hero and the product now has a brand nobody chose.

**Good:** `design.direction` is pending, so the page ships on the primitives that exist, and the pull request names the surface that is waiting on the decision.

## Validation

- `devia decide pending` lists the slot
- `devia check` reports DEC-BLOCKING when a pending slot names a path that exists
