# DEC-005 — A missing asset is never substituted

**Requirement:** When an asset is `pending`, the agent MUST NOT generate, improvise or borrow a stand-in for it. The surface MUST show the absence — an empty slot, or the product name as text — and the register keeps the slot open until its owner delivers it.

**Bad:** A placeholder logo drawn by the agent ships to production because there had to be something in the header.

**Good:** The header renders the product name as text, `brand.logo` stays pending with an owner, and nothing in the repository claims to be the mark.

## Validation

- `devia check` reports DEC-ASSETS when a decided asset path does not exist
- No generated file sits at a path the register calls pending
