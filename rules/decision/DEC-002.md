# DEC-002 — Delegation to an agent is explicit and bounded

**Requirement:** An agent MAY decide only where the register says `delegated`, and only within the stated `bounded_by`. A delegation recorded without bounds MUST be treated as `pending`, not as freedom.

**Bad:** "The agent can pick the test framework", said once in a chat, unbounded — and the project acquires a second runner nobody can remove.

**Good:** `testing.framework: delegated`, `bounded_by: "runs in CI with no network and adds no new runtime"`.

## Validation

- Every `delegated` slot carries `bounded_by`
- `devia validate` fails a delegation with no bounds
