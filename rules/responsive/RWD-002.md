# RWD-002 — Core flows at 320px

**Requirement:** Core flows MUST be usable without horizontal page scrolling at 320 CSS px (except intentional overflow with accessible alternative).

**Bad:** Login requires horizontal scroll.

**Good:** Stacked form layout.

## Validation

- Design or engineering review
