# RWD-003 — Hover not the only path

**Requirement:** Functionality revealed only on hover MUST have a keyboard/touch equivalent.

**Bad:** Delete only appears on row hover.

**Good:** Always-visible overflow menu or focus-revealed actions.

## Validation

- Design or engineering review
