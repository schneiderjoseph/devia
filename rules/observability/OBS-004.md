# OBS-004 — Deployables expose health and readiness

**Requirement:** A deployable service SHOULD expose a liveness signal and a readiness signal that reflects its dependencies, and readiness SHOULD gate traffic during deploys.

**Bad:** A health endpoint that returns 200 while the database connection is dead.

**Good:** Readiness checks the dependencies it truly needs; liveness stays cheap.

## Validation

- Readiness fails when a required dependency is down
