# OBS-003 — Alerts are actionable and owned

**Requirement:** An alert MUST describe a condition a human can act on, name what to do, and have an owner. Alerts nobody acts on MUST be deleted, not muted.

**Bad:** A CPU alert that fires nightly and is ignored by everyone.

**Good:** An alert on user-visible error rate, linked to a runbook, owned by a person.

## Validation

- Each alert has a runbook link and an owner
