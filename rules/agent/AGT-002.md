# AGT-002 — No memory, no code — initialise first

**Requirement:** If `.devia/` does not exist, the agent MUST run `devia init` and fill `00_OVERVIEW.md` from the actual repository before making any other change.

**Bad:** Starting a feature in an unknown repository and inferring the architecture from three files.

**Good:** `devia init`, overview filled from the real stack, then the feature.

## Validation

- `.devia/` exists
- `00_OVERVIEW.md` has no unfilled placeholder

- Status: `active`
- Priority: `P0`
- Exceptions: `none`
