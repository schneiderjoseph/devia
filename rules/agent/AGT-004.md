# AGT-004 — Never invent an interface or a rule

**Requirement:** An agent MUST NOT invent endpoints, fields, configuration keys, business thresholds or third-party behaviour. Unknowns are looked up, asked about, or recorded in `.devia/11_GAPS.md` — never guessed into the code.

**Bad:** Calling `POST /v1/refunds` because that is the usual shape, without checking that it exists.

**Good:** The endpoint list is read; the missing capability becomes a gap line or a question.

## Validation

- Every external call in the diff exists in the contract
- Assumptions are listed
