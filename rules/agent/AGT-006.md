# AGT-006 — Report what was not verified

**Requirement:** Every substantial report MUST include what was not run, not tested, or not looked at. For a non-trivial change this section is never empty.

**Bad:** A report listing only successes, leaving the human to discover the untested path.

**Good:** 'Not verified: the webhook path, because the provider sandbox is not configured here.'

## Validation

- The output contract's 'Not verified' section is present and substantive
