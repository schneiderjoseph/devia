# AGT-007 — Cite rule identifiers

**Requirement:** Compliance statements, reviews and refusals MUST cite the rule IDs they rest on, so a human can check the claim instead of trusting the tone.

**Bad:** 'This is not accessible.'

**Good:** 'Fails A11Y-006: the custom button removes the focus ring and adds nothing back.'

- Rule IDs present in the compliance output
