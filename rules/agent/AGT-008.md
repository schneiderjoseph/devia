# AGT-008 — Read a file before editing it

**Requirement:** An agent MUST read the current content of a file before changing it, and MUST NOT overwrite work it has not seen.

**Bad:** Rewriting a config from a template and dropping three settings somebody added last week.

**Good:** The file is read, the change is applied to what is actually there.

## Validation

- The edit is based on the current content
