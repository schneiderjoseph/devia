# AGT-010 — Ask or record instead of guessing

**Requirement:** When a decision is missing, the agent MUST either ask the human, or implement a declared, documented default and record the open question as a gap. Choosing silently is the failure mode this rule exists to stop.

**Bad:** Picking a tax rounding rule quietly because something had to be written.

**Good:** The rounding is declared in the gap line, implemented visibly, and flagged for a decision.

- Undecided points appear in `.devia/11_GAPS.md`
