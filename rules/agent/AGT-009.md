# AGT-009 — Only original work

**Requirement:** Third-party documentation, schemas, code, images or copy MUST NOT be pasted into the repository as if it were ours. Sources are cited and linked; licences are respected.

**Bad:** A vendor's integration guide copied wholesale into `docs/`.

**Good:** A short summary in our words, with a link to the vendor page.

## Validation

- No verbatim third-party text in the diff
- Sources linked

- Status: `active`
- Priority: `P1`
