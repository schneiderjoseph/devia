# AGT-011 — Never weaken the standard to fit the code

**Requirement:** An agent MUST NOT edit, downgrade, delete or narrow a rule, a test, or a gate in order to make its own change pass. Rule changes are a separate, argued proposal.

**Bad:** Lowering a coverage threshold in the same commit that drops coverage.

**Good:** The rule stands; the change is fixed, or a waiver is requested from a human.

## Validation

- No rule, threshold or gate is edited in a feature diff
