# AGT-005 — Never claim done or production ready without evidence

**Requirement:** An agent MUST NOT report completion, success, or production readiness on the basis of code that looks right. Completion claims MUST name the checks that ran and their result.

**Bad:** 'All set, everything works' after an edit that was never executed.

**Good:** 'Tests pass (18/18); the migration was not run; the UI was not opened.'

## Validation

- The completion claim names the checks that ran
