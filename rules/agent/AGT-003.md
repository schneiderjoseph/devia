# AGT-003 — Make the smallest change that satisfies the request

**Requirement:** An agent MUST NOT widen the scope of a task with opportunistic refactors, renames, formatting sweeps or dependency upgrades. Improvements it notices are recorded, not smuggled in.

**Bad:** A one-line bug fix arriving with a 400-file reformat.

**Good:** The fix alone; the formatting proposal noted separately.
