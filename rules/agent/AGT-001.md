# AGT-001 — Read the memory before writing code

**Requirement:** Before the first edit, an agent MUST read `.devia/AGENTS.md`, `.devia/10_NEVER_ALWAYS.md`, `.devia/00_OVERVIEW.md`, and the memory file covering the surface it is about to touch.

**Bad:** Editing a payment handler without reading what the project already decided about payments.

**Good:** Memory read first; the change follows the recorded decision or challenges it explicitly.

## Validation

- The compliance output names the memory files read
