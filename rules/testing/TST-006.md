# TST-006 — Tests are deterministic and independent

**Requirement:** Tests MUST NOT depend on execution order, wall-clock time, network access, or state left by another test. A flaky test is fixed or removed, never retried into green.

**Bad:** A test that passes locally and fails in CI because it assumes today's date.

**Good:** Time and randomness are injected; each test sets up and tears down its own data.

## Validation

- Run the suite twice in a different order
- No retry loop hides a flake
