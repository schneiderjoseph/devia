# TST-004 — Every bug fix ships with a regression test

**Requirement:** A defect fix MUST include a test that fails before the fix and passes after it.

**Bad:** A one-line fix with the note 'tested manually'.

**Good:** A test reproducing the reported input, committed with the fix.

## Validation

- The test fails when the fix is reverted

## Lifecycle

- Status: `active`
- Priority: `P1`
- Exceptions: `documented-only`
