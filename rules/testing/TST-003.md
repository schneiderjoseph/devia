# TST-003 — Never disable or weaken a test to make CI pass

**Requirement:** Skipping, deleting, loosening an assertion, or widening a tolerance to turn CI green is forbidden. Either fix the code, or record the failure as debt and stop.

**Bad:** `it.skip` added in the same commit as the feature that broke it.

**Good:** The regression is fixed, or the change is reverted and a debt line is opened.

## Validation

- Diff contains no new skip, `only`, or removed assertion
- Coverage did not drop silently

- Status: `active`
- Priority: `P0`
- Exceptions: `none`
