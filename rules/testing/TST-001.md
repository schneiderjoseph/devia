# TST-001 — Business rules are covered by automated tests

**Requirement:** Every rule that decides money, access, state transitions or eligibility MUST have an automated test, including the boundary and the refusal path — not only the happy case.

**Bad:** A discount rule with one test that proves it applies, and none that prove it stops applying.

**Good:** Tests for below, at, and above the threshold, plus the rejection path.

## Validation

- The rule's boundaries appear in the test names
- The test fails when the rule is inverted
