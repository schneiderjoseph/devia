# TST-005 — Critical journeys are covered end to end

**Requirement:** The few journeys the product cannot afford to break — sign in, pay, submit, export — SHOULD have an end-to-end test that exercises the real stack.

**Bad:** Thorough unit tests and a checkout that has never been driven end to end.

**Good:** One end-to-end test per critical journey, run before release.

## Validation

- The journey list exists in `.devia/05_FLOWS.md`
- Each has a test or a named manual step
