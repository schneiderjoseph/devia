# TST-002 — Authorization and isolation paths are tested

**Requirement:** Tests MUST prove that an unauthorized actor is refused and that one tenant cannot reach another's data. Absence of such a test is a P0 gap even when the code looks correct.

**Bad:** Only the authenticated-happy-path is tested; the 403 case is assumed.

**Good:** A test per sensitive route asserting 401/403, plus a cross-tenant read and write test.

## Validation

- Refusal tests exist for the routes touched
- Cross-tenant tests exist
