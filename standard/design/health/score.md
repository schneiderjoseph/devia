# Scoring model (informative)

```text
Accessibility       % of MUST a11y rules passing
Token coverage      UI surfaces using semantic tokens
Component reuse     Screens using system components
Responsive          RWD MUST pass
UX compliance       UX MUST pass
Documentation       Components documented

Overall = weighted average (product-defined weights)
```

Compute in the **application** repo; this standard defines the rubric.
