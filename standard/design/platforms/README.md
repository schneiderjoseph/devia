# Platforms

Rules apply differently by surface. Default assumption is **web**. Override with platform notes when shipping native or touch-first UIs.

| Surface | Notes |
|---|---|
| [`web/`](web/) | Baseline for this standard |
| [`mobile/`](mobile/) | iOS/Android app shells |
| [`tablet/`](tablet/) | Larger touch productivity |
| [`desktop/`](desktop/) | Dense admin / keyboard-heavy |

See also [`interaction/`](../interaction/) for input methods.
