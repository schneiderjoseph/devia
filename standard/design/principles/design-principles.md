# Design principles

1. **Clarity** — one primary job per view
2. **Consistency** — same problem → same pattern
3. **Feedback** — every action shows system status
4. **Forgiveness** — prevent errors; make recovery obvious
5. **Efficiency** — shorten frequent paths; don’t punish experts for novice defaults
6. **Inclusion** — accessible by default, not as polish
7. **Restraint** — remove until it breaks; then put back one thing
