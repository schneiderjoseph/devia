# UX principles

Aligned with NN/g heuristics (interpretive, not a reprint).

1. Visibility of system status
2. Match the real world / domain language of users
3. User control and freedom (undo, cancel, escape)
4. Consistency and standards
5. Error prevention
6. Recognition rather than recall
7. Flexibility and efficiency of use
8. Aesthetic and minimalist design (no irrelevant chrome)
9. Help users recognize, diagnose, and recover from errors
10. Help and documentation when the UI cannot be self-evident
