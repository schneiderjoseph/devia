# Heuristics checklist (NN/g-oriented)

Use during design review. Severity `SHOULD` unless marked MUST elsewhere.

- [ ] Status feedback after actions
- [ ] Domain language matches users
- [ ] Cancel / undo / Escape available where expected
- [ ] Patterns match the rest of the product
- [ ] Errors prevented (constraints, confirms on irreversible)
- [ ] Options visible rather than remembered
- [ ] Shortcuts for frequent power tasks (when relevant)
- [ ] No decorative noise competing with the task
- [ ] Error messages explain problem + next step
- [ ] Help available when flows are non-obvious
