# Naming

```text
{category}.{role}.{variant}.{state?}
```

Examples:

```text
color.text.primary
color.background.surface
space.4
radius.md
button.primary.background
button.primary.background.hover
```

- Prefer English kebab/dot tokens stable across products
- Product branding overrides semantic tokens in a product layer — do not fork core component code per product when tokens suffice
